## 🚀 ЧТО ЭТО ЗА ПРИЛОЖЕНИЕ (по сути)

Открой `orders/models.py`:

from django.db import models  
  
class Client(models.Model):  
    name = models.CharField(max_length=100)  
    phone = models.CharField(max_length=20)  
  
    def __str__(self):  
        return self.name  
  
  
class Order(models.Model):  
    client = models.ForeignKey(Client, on_delete=models.CASCADE)  
    address = models.CharField(max_length=255)  
    delivery_date = models.DateField()  
    volume = models.FloatField()  
    status = models.CharField(max_length=20, default='NEW')  
  
    def __str__(self):  
        return f"Order {self.id}"

# 📍 ШАГ 8. Сделать первую страницу (очень просто)

## 1. В `orders/views.py`:

from django.shortcuts import render  
from .models import Order  
  
def order_list(request):  
    orders = Order.objects.all()  
    return render(request, 'orders/order_list.html', {'orders': orders})

---

## 2. Создать папку:

orders/templates/orders/

## 3. Файл `order_list.html`:

<h1>Список заказов</h1>  
  
{% for order in orders %}  
    <p>{{ order.id }} - {{ order.address }}</p>  
{% endfor %}

---

## 4. В `orders/urls.py`:

from django.urls import path  
from .views import order_list  
  
urlpatterns = [  
    path('', order_list),  
]

---

## 5. В `config/urls.py`:

from django.urls import path, include  
  
urlpatterns = [  
    path('orders/', include('orders.urls')),  
]

---

## Открываешь:

http://127.0.0.1:8000/orders/

# 🔄 Как происходит взаимодействие

Разберём на примере:

---

## 🧩 Пример 1: логист создаёт заказ

1. Логист (клиент) → нажимает "Создать заказ"
2. Браузер отправляет HTTP-запрос
3. Django (сервер):
    - обрабатывает данные
    - сохраняет в БД
4. Сервер возвращает страницу

---

## 🧩 Пример 2: формирование плана

1. Пользователь нажимает:  
    👉 "Сформировать план"
2. Запрос идёт на сервер
3. Сервер:
    - берёт заказы
    - применяет алгоритм
    - создаёт план
4. Отдаёт результат клиенту

---

# 🎯 Очень важный вывод

👉 Сервер **НЕ отправляет данные “другим ролям” напрямую**

Он:

✔ хранит данные  
✔ отдаёт их по запросу

---

## 📌 То есть:

- логист создал заказ
- админ его увидит только когда зайдёт и запросит данные

---

# 🔥 Как правильно сказать на защите

> В системе реализована клиент-серверная архитектура, где серверная часть представлена веб-приложением на Django, обеспечивающим обработку бизнес-логики и работу с базой данных, а клиентская часть — браузером пользователя. Пользователи различных ролей (администратор, логист, транспортный отдел) взаимодействуют с системой через клиентский интерфейс.

# 🧩 1. **Модель — что это такое?**

👉 В Django **модель = это описание таблицы в базе данных**

---

## 💡 Простыми словами:

Модель — это:

> “как будут храниться данные”

---

## 📌 Пример:

class Client(models.Model):  
    name = models.CharField(max_length=100)

👉 Это означает:

В базе данных будет таблица:

|id|name|
|---|---|

---

## 🎯 В твоём проекте модели — это:

- Client (клиент)
- Order (заказ)
- Vehicle (машина)
- Driver (водитель)

---

# 🧩 2. **Миграции — что это такое?**

👉 Это **создание таблиц в базе данных на основе моделей**

---

## 💡 Простыми словами:

Ты написал модель →  
👉 нужно “перенести её в базу”

---

## 📌 Команды:

python manage.py makemigrations  
python manage.py migrate

---

## 🧠 Что происходит:

- Django создаёт таблицы
- добавляет поля
- обновляет структуру БД

---

## 🎯 Аналогия:

👉 модель = чертёж  
👉 миграция = построили дом

---

# 🧩 3. **Админка — что это?**

👉 Это встроенная панель управления в Django

---

## 📌 Где она:

http://127.0.0.1:8000/admin/

---

## 💡 Что мы туда добавляем?

👉 МОДЕЛИ

admin.site.register(Client)

---

## 🎯 Что ты получаешь:

Без программирования интерфейса ты можешь:

✔ добавлять данные  
✔ редактировать  
✔ удалять

---

## 💡 Зачем это тебе:

👉 быстро наполнить базу данными  
👉 не писать формы руками

---

# 🧩 4. **View — это интерфейс?**

👉 ❌ НЕТ  
👉 ✅ Это **логика**

---

## 💡 View — это:

> “что делает сервер, когда приходит запрос”

---

## 📌 Пример:

def order_list(request):  
    orders = Order.objects.all()  
    return render(request, 'orders.html', {'orders': orders})

---

## 🧠 Что здесь происходит:

1. запрос пришёл
2. взяли данные из базы
3. отправили в HTML

---

# 🧩 5. **HTML — это интерфейс?**

👉 ✅ ДА

---

## 💡 HTML — это:

> то, что видит пользователь

---

## 📌 Пример:

<h1>Список заказов</h1>

---

## 🧠 Связка:

View → передаёт данные → HTML → показывает пользователю

# ❌ В чем проблема

Ошибка:

ModuleNotFoundError: No module named 'psycopg2'

👉 означает:

> Django не может подключиться к PostgreSQL, потому что не установлен драйвер

---

# 🧠 Почему это происходит

Ты в `settings.py` указала:

'ENGINE': 'django.db.backends.postgresql'

👉 значит Django ожидает библиотеку:

- `psycopg2` или
- `psycopg`

Но их нет → сервер падает

👉 и всё сразу заработает без установки

from django.shortcuts import render  
from .models import Order, Vehicle, DeliveryPlan, PlanItem  
from datetime import date  
  
def create_plan(request):  
    orders = Order.objects.all()  
    vehicles = Vehicle.objects.all()  
  
    if not vehicles:  
        return render(request, 'error.html')  
  
    vehicle = vehicles[0]  
  
    plan = DeliveryPlan.objects.create(  
        date=date.today(),  
        vehicle=vehicle  
    )  
  
    for order in orders:  
        PlanItem.objects.create(plan=plan, order=order)  
  
    return render(request, 'success.html', {'plan': plan})

## 🔹 Регистрация

from django.shortcuts import render, redirect  
from .forms import RegisterForm  
  
def register_view(request):  
    if request.method == 'POST':  
        form = RegisterForm(request.POST)  
        if form.is_valid():  
            form.save()  
            return redirect('/login/')  
    else:  
        form = RegisterForm()  
  
    return render(request, 'register.html', {'form': form})

---

## 🔹 Вход

from django.contrib.auth import authenticate, login  
from django.contrib.auth.forms import AuthenticationForm  
  
def login_view(request):  
    if request.method == 'POST':  
        form = AuthenticationForm(request, data=request.POST)  
        if form.is_valid():  
            user = form.get_user()  
            login(request, user)  
            return redirect('/')  
    else:  
        form = AuthenticationForm()  
  
    return render(request, 'login.html', {'form': form})

4. появился план с распределёнными заказами →
