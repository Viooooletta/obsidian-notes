Декоратор позволяет прописать код, который будет выполняться до выполнения функции и после, но его мы будем вызывать только при его надобности через @

```
import webbrowser  
  
def validator(func):  
    def wrapper(wa):  
        if "." in wa:  
            func(wa)  
        else:  
            print('Неверный ЮРЛ!!')  
        print('Это текст после функции')  
    return wrapper
    # Круглые скобки не дописываем! Если их жописать, то функция будет выполняться, если не написать, то просто вернем ее значение  
  
@validator  
def open_url(url):  
    webbrowser.open(url)  
  
open_url("https://www.youtube.com/watch?v=tuFuDKE7DF8&list=PLDyJYA6aTY1lPWXBPk0gw6gR8fEtPDGKa&index=20")
```
